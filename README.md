# FitBuddy – AI Fitness Plan Generator using Gemini Models

## 📌 Project Overview

**FitBuddy** is an AI-powered fitness planning application that generates personalized fitness plans using **Google Gemini AI models**.

The application helps users create customized workout and fitness recommendations based on their individual requirements, fitness goals, preferences, and available workout time.

FitBuddy aims to make fitness planning easier, more personalized, and accessible through the power of Generative AI.

---

## 🎯 Objectives

- Generate personalized fitness plans using AI.
- Provide workout recommendations based on user requirements.
- Make fitness planning simple and user-friendly.
- Demonstrate the practical use of **Gemini AI models** in a real-world application.
- Provide users with quick and intelligent fitness guidance.

## 🔄 How It Works

The basic workflow of FitBuddy is:

```text
User Input
    ↓
Fitness Requirements
    ↓
Gemini AI Model
    ↓
AI Processing
    ↓
Personalized Fitness Plan
    ↓
Display Results to User
```

The user provides their fitness-related requirements, and the application sends the relevant information to the Gemini model. The AI processes the request and generates a personalized fitness plan.

## 🚀 Getting Started

### 1. Clone or Download the Project

Download the project source code to your computer.

### 2. Open the Project

Open the project folder using Visual Studio Code or another suitable code editor.

### 3. Configure Gemini API

Create or obtain a Gemini API key through Google AI Studio and configure it according to the project's implementation.

**Never expose your API key publicly or commit it directly to a public repository.**

### 4. Install Required Dependencies

Install the dependencies required by the project.

For Python-based implementations:

```bash
pip install -r requirements.txt
```

### 5. Run the Application

Run the project using the appropriate command for the implementation.

For example:

```bash
python app.py
```

Then open the application in your web browser.

## 🔐 API Key Security

The Gemini API key should be stored securely using environment variables.

Example:

```env
GEMINI_API_KEY=your_api_key_here
```

Do not upload `.env` files containing real API keys to public repositories.
